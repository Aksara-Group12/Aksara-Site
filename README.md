## 🎯 Tentang Proyek Ini

**Aksara-site** adalah situs company profile resmi untuk **Aksara Developer**, software house yang melayani UMKM dan startup di Indonesia. 

Website ini dibangun dengan arsitektur **Static Site Generation (SSG)** menggunakan **Astro**, menghasilkan output HTML murni yang sangat ringan, cepat dimuat, dan aman. Seluruh konten dikelola secara terpusat melalui file TypeScript, memudahkan pemeliharaan tanpa perlu menyentuh kode komponen UI yang kompleks.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---------|-------------|
| ⚡ **Performa Maksimal** | Output statis murni (0kb JavaScript di sisi klien secara default), memastikan *loading time* yang sangat cepat. |
| 🔍 **SEO & JSON-LD Siap** | Dilengkapi `@astrojs/sitemap` dan struktur data `ProfessionalService` JSON-LD untuk peringkat pencarian yang optimal. |
| 📦 **Konten Terpusat** | Semua teks, harga, testimoni, dan data proyek dipisahkan di folder `src/data/`, memudahkan update konten tanpa risiko merusak layout. |
| 🎨 **Desain Modern** | Menggunakan Tailwind CSS v4 dengan *design tokens* kustom untuk tampilan yang konsisten dan responsif di semua perangkat. |
| 🚀 **Deploy Fleksibel** | Bisa di-deploy di mana saja: Vercel, Netlify, Cloudflare Pages, hingga shared hosting (cPanel) statis. |

## 🛠️ Tech Stack

| Bagian | Teknologi |
